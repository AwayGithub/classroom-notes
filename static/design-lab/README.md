## 可体验范围

示例数据支持关键词搜索、科目创建与筛选、改名、调整科目、合并转写（保留原记录）、软删除与恢复、Markdown 导出、批注。录音状态和全文重整为演示；问答为当前科目的示例资料摘录。模型、整理频率、目录设置只保留于本次内存会话。刷新即重置。

真实转录、GPU 模型、持续笔记、自动问题识别、知识库问答与本地存储继续由正式版提供。这一轮用于比较交互方向，尚未连接以上后端能力。
